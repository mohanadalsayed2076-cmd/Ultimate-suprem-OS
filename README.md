# ultimate supremOS 🚀

**ultimate supremos** is a next-generation, ultra-light hybrid operating system project designed for high FPS Steam gaming, Android container integration, and Linux GUI productivity.

---

## Key Features

* ⚡ **1.5 GB Idle RAM Footprint:** Stripped of background bloat and unnecessary telemetry services to leave maximum system resources available for games and applications.
* 🎮 **Unified Steam Gaming Mode:** Bypasses compositor overhead and delivers high FPS performance by uniting Windows DirectX and Linux Proton/Vulkan gaming workloads under a single engine.
* 🐧 **Native Linux GUI Application Support:** Integrated WSL2/WSLg subsystem allowing full-featured Linux apps to run side-by-side with desktop software.
* 📱 **Android Subsystem via Waydroid:** Pre-configured Waydroid container for running mobile apps and games inside floating desktop windows.
* 🔮 **macOS App Support (Targeted for v2.0):** Planned lightweight translation layer to execute native macOS `.app` binaries directly.

---

## System Requirements

| Specification | Minimum | Recommended |
| :--- | :--- | :--- |
| **CPU** | 64-bit Dual-Core Processor | Quad-Core Processor or higher |
| **RAM** | 4 GB RAM (1.5 GB Idle) | 8 GB – 16 GB RAM |
| **Storage** | 25 GB SSD | NVMe SSD |
| **Graphics** | DirectX 11 / Vulkan 1.1 Support | DirectX 12 / Vulkan 1.3 Dedicated GPU |
